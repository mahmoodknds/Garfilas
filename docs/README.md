\# 🍝 Garfilas



> Premium Online Italian Lasagna Experience



\---



\## Overview



Garfilas is a premium online-first Italian restaurant focused on delivering the best lasagna experience through beautiful branding, modern UI, excellent UX and high performance.



The project is not intended to be a traditional restaurant website.



Its goal is to become a digital food brand with an application-like experience.



\---



\## Vision



Create the most memorable online lasagna brand in Iran.



Every interaction should feel



\- Premium

\- Fast

\- Beautiful

\- Simple

\- Memorable

\# Installation



Clone the repository



```bash

git clone <repository-url>

```



Install dependencies



```bash

npm install

```



Run development server



```bash

npm run dev

```



Build



```bash

npm run build

```



Start production



```bash

npm start

```
